# 🏥 醫療數據智慧製圖工具 (Medical Data Visualizer)

這是一個專為醫療專業人員設計的視覺化工具，能將零散的檢驗數據 (Lab Data) 與複雜的用藥紀錄 (Medication) 轉換為直觀的趨勢圖與甘特圖。

## ✨ 核心功能

- **自動化趨勢製圖**：支援肝、腎、發炎、心臟、血糖、電解質、血液及凝血指標等自動分類繪圖。
- **動態用藥甘特圖**：自動解析包含「上午/下午」及「AM/PM」在內的複雜時間格式，並標註 `STAT` 單次醫囑。
- **數據聚合與 SD 顯示**：自動計算同日多筆數據的平均值，並以誤差棒 (Error Bars) 呈現數據離散程度。
- **智慧雙 Y 軸**：針對量級差異巨大的指標（如 WBC 與 CRP），自動開啟雙軸模式以呈現細節趨勢。

## 🚀 快速上手 (使用範例)

請將以下數據分別複製並貼入工具左側的對應輸入區。**每項指標建議獨立換行以獲得最佳解析效果。**

ALT (U/L): 13 (2/20), 102 (2/21), 125 (2/22), 146 (2/23), 127 (2/24), 88 (2/25), 126 (2/26), 76 (2/28), 57 (3/1), 48 (3/2)
AST (U/L): 39 (2/20), 281 (2/21), 199 (2/22), 166 (2/23), 115 (2/24), 68 (2/25), 163 (2/26), 50 (2/28), 33 (3/1), 32 (3/2)
Albumin (g/dL): 2.8 (2/20), 2.7 (2/22), 2.8 (2/25)
CRP (mg/dL): 2.22 (2/20), 11.28 (2/22), 3.74 (2/25), 3.01 (2/26), 1.88 (2/28)
Creatinine (mg/dL): 0.6 (2/20), 0.8 (2/21), 0.9 (2/22), 1 (2/23), 0.8 (2/24), 0.8 (2/25), 0.8 (2/26), 0.8 (2/28), 0.8 (3/1), 0.8 (3/2)

## 🛠 功能說明

- **v22.7.6 更新**：優化了時間解析邏輯，支援 `YYYY/MM/DD 上午/下午` 格式。
- **即時繪圖**：左側輸入，右側即時渲染，支援 PNG 下載匯出。
- **異常標註**：當指標出現劇烈變動（如此例中 2/21 AST 飆升至 281），趨勢圖能直觀呈現斜率變化。

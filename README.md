# 🏥 醫療數據智慧製圖工具 (Medical Data Visualizer)

這是一個專為醫療人員設計的數據視覺化工具，能夠快速將凌亂的檢驗報告 (Lab Data) 與處方紀錄 (Medication) 轉換為直觀的趨勢圖與甘特圖。

## ✨ 核心功能

-   **自動化趨勢圖**：輸入 Lab 數據，自動依照肝、腎、發炎、心臟等指標進行分類繪圖。
-   **用藥甘特圖**：支援複雜的處方格式，自動解析開始與結束時間，並標註 `STAT` (單次執行) 處方。
-   **雙 Y 軸顯示**：針對發炎指標（如 WBC 與 CRP）等數值差異巨大的數據，自動啟用雙軸顯示。
-   **離散數據聚合**：自動計算同日多筆數據的平均值與標準差 (Error Bars)。
-   **高相容性**：支援 `YYYY/MM/DD`、`上午/下午`、`AM/PM` 等多種時間格式。

## 🛠 快捷操作

-   **即時編輯**：修改左側文字區塊內容，右側圖表會即時更新。
-   **圖片下載**：點擊圖表右上方的「📥 下載」按鈕，即可將圖表儲存為 PNG 圖片，方便放入 PPT 或病歷摘要。
-   **STAT 處方標註**：甘特圖中若藥名含 `STAT` 字樣，會自動以 **圓點 (●)** 標示執行時間。

## ⚠️ 注意事項

1.  **時間年份**：Lab 數據若未提供年份，系統預設為 **2026 年**。
2.  **數據格式**：Lab 數據建議採用 `項目名: 數值 (日期)` 格式；處方建議保留原始表格的空格縮排以利解析。
3.  **隱私聲明**：本工具為純客戶端運算 (Client-side)，所有數據僅存在於您的瀏覽器中，不會上傳至任何後端伺服器。
